# Manmeet Singh — Portfolio

A personal portfolio website designed and built entirely from scratch using HTML, CSS, and JavaScript — no frameworks, no templates.

## Live Demo

https://msd2345.github.io/Manmeet-portfolio

## Features

- Custom sword cursor with glow effects
- Animated bonfire and dragon canvas illustrations
- Floating ember particle system
- Scroll reveal animations
- Fully responsive layout
- Dark fantasy aesthetic built entirely with vanilla CSS

## Projects Featured

- Drive AI — Self-driving car simulation using the NEAT algorithm
- Pathfinding Visualizer — Interactive visualizer implementing A*, BFS, DFS, Greedy Best-First, and Bidirectional BFS
- Portfolio Website — This site

## Technologies Used

- HTML
- CSS
- JavaScript

## Setup

No dependencies or build tools required. Just open index.html in a browser.
